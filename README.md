# MY ACADEMIA — 試作版 0.1

「人類の到達点を、あなたの出発点に。」

つながりノートを元にした**別アプリ**。オリジナルの GitHub リポジトリは変更しません。

## 新機能
- マップ内の項目を選択 → 📖 学習ノート
- 横罫線のノート。ページをめくり、文章・画像を順番に追加・編集・削除
- AIとの会話を整理した JSON を項目ごとに取り込み（テキストの貼付・ファイル選択）
- 本文は端末に保存され、既存の「保存書出」JSONバックアップにも含まれます
- チャットの元会話へ戻れる参照 URL を記録可能

## データの安全性
- 別名 `my-academia-v1` でブラウザ保存。元の `tsunagari-v1` と分離
- 元のマップは自動コピーしない。「復元」から旧アプリで書き出した JSON を**追加**読み込みする
- 学習ノートの大量の画像はブラウザの容量制限に注意。定期的に全マップを「保存書出」
- 旧版を上書きしないよう、新規 `my-academia` リポジトリを作り、中身だけアップロードする

## AIに渡す指示の例
「ここまでの対話をマイアカデミア用に出力してください。JSONのみ。形式：{"format":"my-academia-note-v1","title":"今日の学習","blocks":[{"type":"text","text":"要点と説明"}]}。事実と推測を区別し、分からないことは不明と書いてください。画像はアプリ側で別途追加します。」

※画像を含む会話をリンクだけで直接取り込むことはできません。画像は保存してノートに挿入してください。
